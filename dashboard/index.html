Token Launch Radar

Every pre-token protocol in the snapshot, ranked by an implied value derived from the snapshot's own market: the median market-cap / TVL of the token-bearing protocols in its category, shrunk toward the global median when the sample is thin, then adjusted for the last week's TVL momentum and for how long the protocol has run without a token. Only a genuine launch candidate is ranked: a protocol that records no token and is not a wrapped, staked or bridged product of a token that already trades — the snapshot's own watchlist rule, applied to the whole board — so a wrapped product never tops the board on its TVL alone.
