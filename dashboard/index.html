Token Launch Radar

Every pre-token protocol in the snapshot, ranked by an implied value derived from the snapshot's own market: a size curve fitted to the snapshot's token-bearing protocols — log market cap against log TVL, with a fitted intercept per category — and tested held-out twice before it was used. A token's value grows roughly with the square root of TVL, not in proportion to it, so a flat multiple would overprice the giants and underprice the small. Only a genuine launch candidate is ranked: a protocol that records no token and is not a wrapped, staked or bridged product of a token that already trades — the snapshot's own watchlist rule, applied to the whole board — so a wrapped product never tops the board on its TVL alone.
